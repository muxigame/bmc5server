# CustomNPCs 商人独立库存

本地开发版本：`1.21.1.20251230-bmc-stock.1`。这是在重建基线上新增的游戏功能，不再与原模组行为等价。

## 使用方式

OP 持 NPC 魔杖打开商人设置，在商品格旁点击“库存”，启用限制，填写库存上限及补货间隔（秒），点击“完成”，退出商人设置以保存。旧 NPC 默认无限库存，需逐格启用。

玩家看到的 18 项交易分为三页，每页六项。商品旁只增加库存数量和补货倒计时。库存不足以交付一整份商品时不扣钱、不发货；普通点击和 Shift 连买共用同一服务端校验。

## 已确定的规则

| 项目 | 行为 |
| --- | --- |
| 共享范围 | 同一 NPC、同一商品格的所有玩家共享 |
| 库存单位 | 实际交付的物品个数；例如一份兑换给 4 个，库存 20 支持 5 份 |
| 补货 | 按真实时间计时，到期补满至上限，不累加 |
| 离线或区块卸载 | 保存余量和下次补货时间；重新加载时补算已到期周期，仅补满一次 |
| 默认兼容 | 缺少新字段的旧 NPC 保持无限库存 |
| 修改上限 | 降低时裁剪余量；提高时保留余量，等下次补货 |
| 修改间隔 | 从修改时重新计时 |
| 关闭再启用 | 重新给予满库存，是管理员显式进货操作 |
| 同名市场模板 | 共享商品与设置；不同 NPC 的运行库存各自独立 |
| 范围 | 上限 1–1,000,000 个，间隔 1–31,536,000 秒 |

## 实现和兼容

库存扣减只由服务端完成；脚本修改交付数量、取消交易或触发嵌套购买后重新校验。编辑器保存只应用设置，不允许把旧的运行库存覆盖回服务器。限制配置及市场模板操作要求 OP 等级 2。UI 使用原模组的按钮、文本框、背景和 Minecraft 字体，没有图片文字或外部字体。

新增 NBT 字段为 `BmcTraderStockSettings` 与 `BmcTraderStockState`。原有字段和 18 个商品槽 ID 保留。菜单整数拆成两个 16 位值同步，避免大库存截断。

网络协议标识改为 `bmc-stock-1`，客户端与服务端必须配套更新；旧客户端不能混用。候选 JAR 未安装到正常客户端和服务端目录，也未部署正式服。
