# 地基空气保护（0.6.3，待审阅）

建筑埋入地面时，完整覆盖保存的空气会挖空地基周边。新增「地基：开/关」，默认关闭；开启后仅跳过底部指定层的空气，以上空气仍清空目标。原NBT无需重存。

「地基设置」自动识别连续实心、同层连通且不围住空气的底层，并显示顶层世界Y；开放门洞、柱式及异形地基可人工修正层数。开关保持本次登录的选择，新建筑重新识别层数。预览计数和放置共享过滤结果；变更设置会取消旧确认，箱内物品、完整备份和撤销受回归覆盖。

验证：55项实际GameTest（新增7项）通过；开发客户端GUI夹具验证入口、输入、返回、二次确认和顶层Y，发行包排除测试类。没有冒称完整整合包联机端到端通过。

升级：客户端和服务器一起切换到本候选分支；正常关闭后分别运行仓库原有setup。锁定的0.6.3通过Git LFS地址下载并校验，旧0.6.2仅在校验吻合时移入既有回退目录；自定义JAR不覆盖。协议5拒绝旧端混接。审阅前不部署或重启正式实例。

回滚：两端共同切回目标分支的0.6.2锁定清单，停止实例后恢复已校验的0.6.2（移走0.6.3，勿同时加载两份），再运行verify。建筑和世界无需格式转换。
