# CustomNPCs motion.118 阶段定版

Minecraft 1.21.1 / NeoForge 21.1.250 / Java 21。客户端、服务端必须使用同一JAR，退出对应实例后再替换，不能同时装旧CustomNPCs。

## 使用现有仓库安装

更新到本次PR对应分支后，正常运行服务端 `python tools/server.py setup` 或客户端 `python tools/client.py setup`，安装器会下载并校验新JAR及NPC设计补充包。原资源大ZIP、MCEF和其他模块的锁定不变。已有已知旧NPC JAR经校验后备份退役；未知修改停止安装。

设计补充包仅包含cpn_steve/cpn_alex默认适配模型、皮肤/分段护甲/动作，以及两份设计模板、设计填写表和音效署名，不含其它人物模型。补充资源只补缺失文件，保留已经手改的文件；无需覆盖既有世界或玩家数据。

YSM本体仍使用原作者的2.6.5对应NeoForge版，不打入NPC JAR。精钢武器专属玩家战斗需要现有精钢锻造模组（本次验证0.6.3）；本次未替换或发布其开发源码。没有该模组时，不启用这些武器专属玩家规则。原版武器不套用这些修改。

## 手动安装

将CustomNPCs JAR安装到两端mods，先备份并移出旧NPC JAR。解压NPC-Design-Kit-motion118.zip到对应游戏目录；其中kit-manifest.json用于核验。保留自己的模型修改，不覆盖world或玩家live.nbt。管理员物品NPC魔杖 → 设计与恢复可导入客户端customnpcs/designs中的两份.design.json；NPC/玩家分区必须对应，导入只是草稿，检查后再保存。也可以使用NPC入口恢复默认，应用当前完整默认人形预设。

当前测试世界的完整默认NPC已经按新伤害升级。其它旧NPC不会静默改动；管理员可显式执行 `noppes npc "NPC名称" releasedefaults`，先自动备份后按招数库平均伤害+50%升级，重复执行不叠加。新完整默认NPC直接使用定版值。

默认八个近战招数：第一刀7、第二刀8、格挡反击8、冲刺下劈8、后撤反击7、踏前戳刺8、左右侧挡快反各7；算术平均5→7.5，增加50%。投石2→3，无伤害动作保持0。保留原整数结算，因此没有全部写7.5再被向上取整成8。实战DPS还受概率、节奏和防御影响。

## 后续定向制作

填写docs/NPC-DESIGN-TEMPLATE.md：基本资料、阵营装备、生存/失衡/防御、感知与战术、每招动作/伤害/条件/位移、连招、外观音画和验收场景。留空沿用motion.118。

NPC设计、玩家设计及YSM外部资源作用范围分开；每NPC配置的备份/导入导出/恢复默认/历史回退沿用。外部模型、贴图、声音资源需另做文件备份，不能声称NPC设计快照覆盖这些文件。

## 验证

实际八招无甲伤害7/8点、可回退和不重复升级等41项检查通过；战术871项、背敌脱离297项、徘徊3132项，以及Steve/Alex剑和Steve斧各490样本走跑/攻防/刀光回归通过。安装器服务端49项、客户端40项通过。验证范围是独立CustomNPCs+精钢+YSM测试；不是全部BMC模组的全玩法认证。验证摘要见validation.json。
