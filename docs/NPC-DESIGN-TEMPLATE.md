# NPC 定向设计填写表（motion.118）

复制本表填写后发给我即可。空白或“沿用默认”表示采用 motion.118 的完整默认NPC，不表示删除功能。距离单位为方块，时间建议填写秒，概率填写0–100%；20 tick = 1秒。伤害填写护甲结算前白值，实际扣血受护甲、伤害种类、眩晕等影响，沿用整数向上取整。

## 5. motion.118 默认伤害参考

| 招数 | 原伤害 | 新白值 / 无甲实测伤害 |
|---|---:|---:|
| 第一刀 | 5 | 7 |
| 第二刀 | 5 | 8 |
| 格挡反击 | 5 | 8 |
| 冲刺下劈 | 5 | 8 |
| 后撤反击 | 5 | 7 |
| 踏前戳刺 | 5 | 8 |
| 左侧格挡快反 | 5 | 7 |
| 右侧格挡快反 | 5 | 7 |
| 八招算术平均 | 5 | 7.5（+50%） |
| 远距投石 | 2 | 3 |
| 徘徊等无伤害动作 | 0 | 0 |

伤害配成整数是为了遵守既有向上取整结算；全部填写7.5会被结算成8，因而改为四招7、四招8。它是招数库的算术平均，实战每秒伤害还取决于选招概率、前后摇与防御，不保证所有打法DPS恰好+50%。
