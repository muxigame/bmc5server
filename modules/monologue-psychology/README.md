# 独白与心理 0.1.1

独立模组 `inner_monologue`，适用 Minecraft 1.21.1 / NeoForge 21.1.250；客户端和服务器均须安装。

## 默认关闭（0.1.1）

为避免遮挡敌人，系统暂时默认关闭，头顶独白与心理文字都不会自动显示。旧版存档首次升级也会关闭一次，保留全部自定义台词。打开 /monologue → 显示设置 → 系统：关，可手动开启或关闭；手动选择会保存，重启保持。恢复默认会重新关闭系统。

## 效果（手动开启后）

- **头顶独白**：情境发生后在玩家头顶显示，32格内同维度玩家可见。装有工作区 CustomNPCs 时直接调用其 `ChatMessages` 原生绘制器，使用同样的白底、黑边、气泡尾巴。头顶坐标根据相机投影，随距离缩放；4格以外会检查方块遮挡。玩家用 F5 第三人称查看自己的头顶气泡；第一人称不会把头顶框挡在镜头前。
- **心理活动**：仅发给角色本人；准星正下方24个GUI像素，透明底、无边框，只显示浅色文字。没有内容时完全不绘制；默认4秒后消失，最后半秒淡出。打开菜单或隐藏HUD时不显示。
- 不发送聊天消息，不播放声音，不修改攻击、伤害、食物、NPC台词或世界方块。角色死亡、重生、退出或换世界后不保留旧心理文字。

## 首版情境

| 情境 | 触发条件 | 默认冷却 | 头顶例句 | 心理例句 |
|---|---|---|---|---|
| 受到攻击 | 来自其他生物或玩家的攻击造成实际扣血，且玩家仍存活 | 3秒 | 嘶……！ | 稳住，别再露出破绽。 |
| 击杀敌人 | 玩家击杀或获得击杀归属：敌对怪物、正以玩家为目标的生物/NPC、非同队玩家 | 4秒 | 结束了。 | 先确认四周，还有没有别的敌人。 |
| 进食 | 真正完成食用带 FoodProperties 的食物 | 5秒 | 先吃点东西。 | 趁现在补充体力，等会儿再赶路。 |

每个情境的头顶和心理分别内置3句（共18句），随机选择并尽量避免连续重复。同类情境冷却相互独立。受击优先于击杀，击杀优先于进食，低优先级不会盖掉尚未结束的高优先级台词，不排长队。

摔伤、饥饿等无生物来源伤害、完全格挡或无敌免伤不算受击。普通牲畜、同队单位、自己的驯服动物不算敌人。喝牛奶、普通药水、吃到一半取消不算进食。观察者不触发；创造玩家可以预览，实际事件仍需满足相应条件。此次未增加饥饿、天气、睡眠等额外心理情境。

## 自定义台词

输入 `/monologue`，或在 CustomNPCs 的任务日志（默认 L）、阵营页、NPC主菜单点击右下方 **独白与心理**。该按钮位于“真实需求”左边，不覆盖旧入口。

1. 选择受到攻击、击杀敌人或进食。
2. 选择“头顶独白”或“心理活动”。
3. 用上一条/下一条浏览，编辑输入框后点击“保存此条”；也可以新增或删除。每组最多12句，每句1–96字符。
4. “显示设置”可修改当前情境的时长和冷却、心理文字向下偏移，以及整个系统/头顶/心理的开关。20刻为1秒；显示20–200刻、冷却20–1200刻；偏移12–120个GUI像素。
5. “预览此情境”会关闭菜单，仅向本人发送预览。F5可看到自己的气泡。也可用 `/monologue preview hurt`、`kill` 或 `eat`；`/monologue help` 查看简短帮助。

台词库是**服务器世界通用配置**。普通玩家可查看和预览；修改需要管理员权限等级2。修改立即验证、保存并给出成功反馈。删除某组全部台词会静默该组，重新读档不会补回默认句子。其他情境和频道不受影响。

“恢复默认”恢复整套设置；“撤销修改”恢复上一次配置，包括重启后。编辑有版本检查，另一个管理员先保存后，旧页面提交会被拒绝并刷新，防止覆盖他人修改。配置保存在世界 `data/inner_monologue.dat`，包含配置版本和上一版完整快照，需更早版本时使用联合世界备份。

## 联动与限制

不替换 CustomNPCs JAR，不复制其绘制源代码；仅调用已安装模组的公开客户端方法。未装 CustomNPCs 或其API不兼容时仍可用命令和心理HUD，头顶降级为简单白底文字。若 CustomNPCs 全局关闭了聊天气泡，其原生绘制入口也遵守该开关。

敌对NPC依靠实体当前攻击目标识别，未进入敌对状态且不属于 Enemy 类型的自定义实体不会一律算敌人。内置台词是全局文案，不推断真实情绪，不读取玩家输入或外部数据。

## 构建与验证

```powershell
./dev.ps1 build
./dev.ps1 runGameTestServer
```

JDK为工作区 `dependencies/jdk-21.0.12.1+1`。发行包 `dist/inner_monologue-0.1.1.jar` 不含 GameTest 类和空白测试结构。13项GameTest覆盖配置持久化/回退、并发编辑拒绝、文本边界、空台词、冷却、轮换、显示优先级、私人数据分发、敌人分类、伤害和击杀事件、进食事件、权限。GameTest模拟玩家固定创造且带出生保护，受击测试使用绕过保护的伤害类型走真实扣血/Post事件路径。

联合实例固定 `../npc-forging-test`。部署前读取最新清单、正常关闭实例、备份世界，再用 `Update-Mod.ps1 -ModId inner_monologue -JarPath <文件>` 安装双端。保留其他所有模组，最终版本以联合清单为准。验证记录见 `reports/`。
