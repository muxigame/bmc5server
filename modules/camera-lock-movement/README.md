# 视角，锁定与万向移动 0.1.3

Minecraft 1.21.1 / NeoForge 21.1.250 / Java 21。模组 ID：`camera_lock`。

独立 JAR，不依赖 CustomNPCs、YSM 或精钢锻造。这里的“原版使用”指安装 NeoForge 后搭配原版内容；未安装加载器的纯原版客户端不能加载模组。CustomNPCs 存在时，通过可选反射桥接读取阵营友好/中立关系，无编译链接或必装依赖。

## 操作

- F5 进入第三人称。两个第三人称档位统一使用战斗背后镜头；第一人称不接管。
- WASD：按镜头水平朝向移动；未锁定时角色转向实际移动方向，S 可以转身向镜头后方走，组合键支持斜向。
- 鼠标中键：在前方半球、20 格球形范围、可见且无遮挡的目标中锁定/解除。设置 → 控制 → 按键绑定可以改键。
- 优先级：敌对 CustomNPCs → 原版/兼容 Enemy 怪物及当前攻击玩家的 Mob → 中立 NPC → 友善 NPC。同级选最近，不锁普通动物或其他玩家。
- 锁定时角色持续面对目标，移动仍按镜头方向转换，可绕目标移动；准心立即跟随目标，镜头用约 247.5ms 过渡。
- 锁定时同侧连续快速甩鼠标两次，切换到该侧角度最近的可见目标。每次 180ms 内跨过约 28° 的等效输入阈值，完成两次的间隔不超过 650ms。每次越界隐形光标回中，但同一次甩动的后续输入不会再次计数。停手至少 90ms 或明显回拉约 6° 后才重新允许计数；进入反侧区域后按反侧重新计数。慢慢挪鼠标不触发。
- 弓拉弦、已装填箭的弩、蓄力三叉戟自动使用隐藏的弹道瞄准。视觉准心仍显示目标，不显示抛物线准心。

## 行为

镜头位于眼睛上方 0.65 格、向后约 4 格；八角碰撞探测缩短镜头距离。横移时允许少量肩部偏移，设置了屏幕半侧最大 15% 的横向上限。相机与玩家实际转向分开，因此改变移动朝向不会把镜头一并拖转。

转场前 192.5ms 快速旋转，末尾 55ms（原 27.5ms 加倍）的速度由快速段的 50% 线性减到 10%，用积分曲线归一化到目标角度。解锁回到锁定前的自由镜头方向，之后继续鼠标控制。目标死亡、离开范围、不可见/遮挡时解除；开菜单不收集手势，切换第一人称清除锁定。

弹道计算使用离散阻力、重力、目标速度及原版武器继承的射手速度。发射/松弦前先发送玩家方向，再走原版使用物品流程；不修改伤害、射程、弹药、碰撞、随机散布或 NPC 战斗代码。

## 当前边界

- 预判按目标保持当前速度计算；突然变向、碰撞、网络延迟及原版随机散布仍可能导致未命中。
- 已适配原版弓、箭弩、三叉戟。烟花弩、水下、特殊模组武器弹道仅普通朝向锁定，不承诺弹道补偿。骑乘、睡觉和旁观模式暂停接管。
- NPC 桥接使用客户端已同步的阵营数据；未知 NPC API 回退为中立（正在攻击玩家的回退为敌对）。
- GameTest 验证的是实际箭实体的飞行/伤害，不等于完整鼠标蓄力→网络发射→实战命中率测试。万向移动和切换手感仍需用户试用调整。

## 0.1.3 方块交互修正

未锁定时，交互射线改为屏幕中心实际画面方向，不再沿角色身体朝向。每帧按实际相机和投影矩阵计算，兼容镜头侧移、视野变化、走路晃动及受击倾斜；方块轮廓与实际点击共用同一个命中结果。按钮仍按自身真实形状选择，没有扩大范围或自动代选旁边按钮。

准心增加实心中心和黑色描边，消除原版与自定义准心重叠。可触及时变绿并显示方块名称；太远或被遮挡时变灰并注明原因。眼睛到目标的原版交互距离和遮挡检查保留，第三人称相机后移不会额外增加距离。右键方块前同步朝向以配合原版放置/物品交互。锁定战斗及第一人称沿用原逻辑；要操作方块时先中键解除敌人锁定。

新增5项GameTest：真实小按钮命中并实际通电、超距拒绝、镜头越墙但玩家视线被挡时拒绝、左右肩部偏移、不同FOV/晃动投影下屏幕中心对齐。连同原5项共10项通过；纯Java 2020断言通过。首轮遮挡夹具相机高度不足而自身也撞墙，已修夹具高度后复测，未修改遮挡规则来迁就测试。

## 0.1.4 简化交互提示
第三人称未锁定时隐藏准心和全部方块名称；锁定单位只显示3×3白点，不显示名称/十字。按钮本体用白色轮廓高亮，镜头射线落在按钮外扩0.22格区域且按钮可见、玩家可触及时，选择真实按钮并发送真实命中位置；不扩大实体碰撞箱或玩家操作距离。优先保留直接命中的按钮/实体，附近多个按钮按离中心射线最近选择。第一人称在所有HUD/射线/高亮/朝向修改入口均旁路，继续使用原版瞄准。
构建2020数学检查和11项无NPC GameTest通过，新增偏离按钮本体仍选中并真正按下、越距不辅助的验证。高亮渲染已编译；不宣称完成物理鼠标手感验收。

## 0.1.5 拉杆、门、箱子
第三人称未锁定时，按钮、拉杆、门、普通/陷阱/末影箱共用白色轮廓和0.22格交互辅助；对准边缘外侧空气也会在镜头射线附近搜索可见目标。优先保留直接命中的可互动方块与实体，保留角色距离和双方视线检查。不改变铁门的红石要求、箱子原版开启条件或方块碰撞。第一人称全部旁路，仍不显示名称；未锁定无准心，锁定白点不变。
